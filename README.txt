SYNCED DOORS (Forge 1.20.1)

Что делает мод:
- Двойные двери (две двери рядом, петли по краям) открываются и закрываются вместе:
  рукой, от кнопок, рычагов, нажимных плит и любой другой редстоун-схемы.
- Работает с железными дверями и с дверями из других модов, если они сделаны
  на основе ванильного класса двери.
- Две соседние калитки в ряд тоже открываются вместе.
- Для дверей, калиток и люков добавлен лёгкий звук у второй створки и облачко пыли.
- Плавный поворот (анимация) пока не добавлен, это следующий шаг.

Сборка без установки Java (через GitHub):
1. Распакуйте архив целиком.
2. Создайте на github.com новый репозиторий.
3. Add file -> Upload files, перетащите ВСЁ содержимое распакованной папки:
   файлы build.gradle, settings.gradle, gradle.properties и папки src и .github.
   Проверьте, что в списке загрузки есть пути src/main/java/... и .github/workflows/build.yml.
4. Вкладка Actions -> дождитесь зелёной галочки -> внизу в Artifacts скачайте jar.
5. Положите jar в папку mods (Forge 1.20.1, версия 47.x).

Настройки (в начале файла SyncHandler.java):
PAIR_DOORS, PAIR_GATES, PAIR_TRAPDOORS, REQUIRE_SAME_BLOCK, PARTICLES, PARTNER_SOUND_VOLUME.
